# Embedded Fonts

BeatCheck embeds the following open-source typefaces directly into the portable binary under the **SIL Open Font License 1.1 (OFL-1.1)**:

- **Space Grotesk** (`SpaceGrotesk-Medium.ttf`, `SpaceGrotesk-Bold.ttf`) — Copyright © Florian Karsten
- **Inter** (`Inter-Regular.ttf`, `Inter-SemiBold.ttf`) — Copyright © Rasmus Andersson
- **JetBrains Mono** (`JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf`) — Copyright © JetBrains s.r.o.
